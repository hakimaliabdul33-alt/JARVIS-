VYRA

Share Your World

VYRA is an Android social-video platform designed for discovering, sharing, and interacting with short-form videos.

📱 About VYRA

VYRA brings short videos, social interaction, creator profiles, and personalized content discovery together in one simple experience.

Users can watch videos in a fullscreen vertical experience, interact with creators, follow profiles, save videos, comment, like, and share content.

✨ Features

- 🎬 Short-form video feed
- 📱 Fullscreen vertical video viewer
- ⬆️ Video upload and publishing
- ❤️ Like videos
- 💬 Comment on videos
- 🔗 Share videos
- 🔖 Save videos
- 👤 User profiles
- ➕ Follow / unfollow users
- 👥 Followers and following system
- 🔎 Search and discover content
- ▶️ Automatic video playback
- 📊 Video view tracking
- 🌐 Cloud-based video storage
- 🔥 Engagement-based content discovery
- 🌓 Dark mode support
- 📢 Advertisement support

🔥 Content Discovery

VYRA is designed to make engaging content easier to discover.

Video engagement such as:

- Likes
- Comments
- Shares
- Views

can be used as signals for determining how content is distributed in the feed.

The goal is to give engaging videos an opportunity to reach more viewers while keeping the feed dynamic and continuously updated.

👤 Profiles

Each VYRA user can have a personal profile containing:

- Display name
- Username
- Bio
- Profile photo
- Followers
- Following
- Uploaded videos

Users can open creator profiles directly from videos, search results, and comments.

☁️ Backend

VYRA uses cloud services for authentication, user data, video information, social interactions, and media storage.

Firebase

Firebase is used for:

- Email/password authentication
- User profiles
- Followers
- Following
- Likes
- Comments
- Video metadata
- View tracking

Supabase

Supabase storage is used for hosting uploaded video files and providing public video URLs.

🛠️ Technology

VYRA is an Android application built using:

- Java
- Android SDK
- Gradle
- Firebase
- Cloud Firestore
- Firebase Authentication
- Supabase Storage
- Google Mobile Ads

📦 Building VYRA

Clone the repository:

git clone https://github.com/hakimaliabdul33-alt/VYRA.git
cd VYRA

Build the debug version:

./gradlew assembleDebug

The generated APK can be found at:

app/build/outputs/apk/debug/app-debug.apk

🔐 Configuration

Before building or deploying VYRA, configure the required Android, Firebase, Supabase, and advertising credentials.

Do not commit private credentials, API secrets, service-account files, or other sensitive configuration data to the repository.
